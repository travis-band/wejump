# 07. 배포 방법 비교와 이 구성을 고른 이유

> 가격은 2026년 9월 기준으로 확인한 값입니다. 클라우드 가격과 무료 정책은 자주 바뀌니 수업 전에 한 번 더 확인하세요. 아래 출처 링크를 참고하세요.

## 추상화 사다리

아래로 갈수록 직접 하는 일이 줄고, 안이 덜 보입니다.

| 단계 | 예시 | 내가 관리하는 것 | 플랫폼이 관리하는 것 |
|---|---|---|---|
| 내 컴퓨터 | localhost, ngrok | 전부 (컴퓨터가 켜져 있어야 함) | 없음 |
| VPS (가상 서버) | GCP Compute Engine, AWS Lightsail, DigitalOcean | OS, Docker, 프록시, 배포 스크립트, DB | 하드웨어, 네트워크 |
| 서버리스 컨테이너 | GCP Cloud Run | 이미지, 트래픽 비율, 권한(IAM) | 서버, 확장, HTTPS |
| PaaS | Render, Railway, Koyeb | 코드와 설정 파일 하나 | 빌드, 서버, HTTPS, 무중단 배포 |
| 프론트엔드 특화 | Vercel, Firebase Hosting | 코드 | 거의 전부. 대신 정해진 모양만 가능 |

## 이 구성을 고른 이유

**목표가 "편한 배포"가 아니라 "배포의 원리를 가르치기"라서, 두 트랙으로 나눴습니다.**

- **트랙 1 = GCP e2-micro VPS.** 서버, 프로세스, 포트, 프록시, 인증서, 볼륨, blue/green 스위치가 전부 레포 안의 파일과 서버 안의 명령으로 보입니다. 비용 $0이고, 같은 파일이 어느 리눅스 서버에서든 그대로 돕니다.
- **트랙 2 = Render + Neon.** 트랙 1에서 직접 한 일을 플랫폼이 대신해 주는 경험. 카드 없이 $0, 15분이면 됩니다. 트랙 1과 같은 `Dockerfile`을 쓰므로 "코드는 같고 관리 주체만 다르다"는 비교가 성립합니다.

## 뺀 선택지와 이유

| 선택지 | 뺀 이유 | 이럴 때는 좋은 선택 |
|---|---|---|
| **Vercel** | 파이썬을 컨테이너가 아니라 요청마다 잠깐 도는 서버리스 함수로만 실행합니다. `Dockerfile`을 지원하지 않아 두 트랙이 같은 이미지를 쓴다는 원칙이 깨집니다. 자체 DB도 없어 결국 Neon을 연결해야 합니다. | 앱이 Next.js이거나, 정적 HTML/JS에 API 몇 개만 붙은 형태. 바이브코딩한 프론트엔드 결과물을 5분 만에 올릴 때 |
| **Firebase** | Firebase Hosting은 정적 파일만 서빙합니다. 파이썬 API는 결국 Cloud Run에 따로 올려야 하고, DB는 Firestore(NoSQL)가 되어 Postgres 수업과 맞지 않습니다. Firebase App Hosting은 Next.js와 Angular 위주이고 파이썬은 직접 컨테이너 + Terraform이 필요합니다. | 정적 사이트, 또는 Firestore와 Firebase 로그인을 쓰는 앱 |
| **GCP Cloud Run + Cloud SQL** | 각 부품이 GCP 콘솔의 제품으로 보이는 장점이 있지만, 머신·프로세스·포트는 보이지 않습니다. Cloud SQL이 월 $8~10 고정. GitHub에서 GCP로 인증하는 설정(서비스 계정, Workload Identity)이 중고생에게 어렵습니다. | 트랙 1 다음의 심화 수업. 리비전별 트래픽 비율(10% → 50% → 100%) 슬라이더는 카나리 배포를 보여 주기에 아주 좋음 |
| **GCP Cloud Run + Neon** | 위와 같지만 $0 | 같은 이미지를 Cloud Run에도 올려 보는 세 번째 트랙으로 확장 가능 |
| **AWS Lightsail** | 1GB 요금제가 $7. GCP e2-micro와 사양은 비슷한데 유료 | 서울 리전이 필요할 때 (응답 속도) |
| **Oracle Always Free** | 가입 거절과 리전 용량 부족이 잦아 수업 준비가 불안정. ARM이라 이미지도 ARM으로 빌드해야 함 | 사양이 큰 무료 서버가 꼭 필요할 때 |
| **Railway** | 무료로 계속 쓸 수 없음 ($5/월) | 잠들지 않는 PaaS가 필요하고 월 $5가 괜찮을 때 |
| **GCP 관리형 로드밸런서** | 월 약 $18. 서버 한 대에는 과함. Caddy가 같은 역할(HTTPS, 전환, 분배)을 서버 안에서 함 | 서버가 여러 대가 될 때 |
