# 01. 내 컴퓨터에서 실행하기

**목표**: 방명록 앱을 내 컴퓨터에서 띄우고, 코드가 어떻게 나뉘어 있는지 이해한다. 그리고 "왜 이것만으로는 부족한지" 느낀다.

## 준비물

- Python 3.12
- Docker Desktop (지금은 DB를 켜는 스위치로만 씁니다. 원리는 [02-도커](02-도커.md)에서)
- 이 레포: `git clone https://github.com/<깃허브아이디>/wejump.git && cd wejump`

## 따라 하기

```bash
# 1. DB 켜기 (Postgres가 5432번 포트에서 대기)
docker compose up -d db

# 2. 파이썬 가상환경 + 라이브러리 설치
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt

# 3. 설정 파일 만들기 (DB 주소가 들어 있음)
cp .env.example .env

# 4. 앱 실행
uvicorn app.main:app --reload --env-file .env
```

브라우저에서 <http://localhost:8000> 을 열고 글을 남겨 보세요. 화면 아래에 `local` 배지가 보입니다.

DB에 직접 접속해서 글이 저장되는 걸 보고 싶다면 [02-1-로컬DB](02-1-로컬DB.md)를 보세요.

## 코드 구조

```
app/
├── main.py      백엔드. 주소(/api/messages 등)마다 무엇을 할지 정함
├── db.py        DB와 대화하는 SQL
├── static/      프론트엔드. 브라우저로 내려가서 브라우저에서 실행됨
│   ├── index.html
│   ├── style.css
│   └── app.js   fetch('/api/messages')로 백엔드에 요청
└── tests/       자동 테스트
```

글 하나를 남기면 이렇게 흘러갑니다.

```
app.js  ──POST /api/messages──▶  main.py  ──INSERT──▶  Postgres
(브라우저)                        (서버)                  (DB)
```

## 테스트

```bash
pytest -v
```

3개가 통과해야 합니다. 나중에 [04-자동화](04-자동화.md)에서 GitHub가 배포 전에 이걸 대신 돌려 줍니다.

## 실험

1. **영속성**: uvicorn을 `Ctrl+C`로 끄고 다시 켜 보세요. 글이 남아 있나요? 글은 앱(파이썬 프로세스)이 아니라 DB에 있기 때문입니다.
2. **localhost의 한계**: 폰으로 `http://localhost:8000` 을 열어 보세요. 안 열립니다. `localhost`는 "지금 이 기계 자신"이라는 뜻이라, 폰에서는 폰 자신을 가리킵니다.
3. **내 노트북을 서버로**: 같은 와이파이라면 이렇게 해 볼 수 있습니다.
   ```bash
   uvicorn app.main:app --host 0.0.0.0 --env-file .env
   ipconfig getifaddr en0          # 맥의 내부 IP, 예: 192.168.0.12
   ```
   폰에서 `http://192.168.0.12:8000` 을 열면 됩니다. 방금 내 노트북이 서버가 됐습니다. 하지만 노트북을 덮으면 끝이고, 와이파이 밖에서는 안 되며, 자물쇠(HTTPS)도 없습니다.

   (ngrok 같은 도구를 쓰면 외부에서도 들어오게 할 수 있지만, 노트북이 켜져 있어야 한다는 문제는 그대로입니다.)
